# AOT Technologies design system

1. Read [DESIGN.md](DESIGN.md) in full before you generate or review any UI
   or copy for AOT Technologies.
2. Use only the tokens and components it defines. Don't invent colours,
   sizes, radii, shadows, fonts or spacing. If you need something it doesn't
   cover, say so instead of guessing.
3. Follow its voice and naming rules in all copy.
4. Use it only for AOT Technologies. Don't combine it with the formsflow.ai
   design system.
